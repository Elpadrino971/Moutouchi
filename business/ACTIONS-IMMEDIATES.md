## ⏰ BLOC 1 : Créer le questionnaire (20 min)

### Étape 1 : Ouvrir Google Forms (2 min)

1. Aller sur https://forms.google.com
2. Cliquer sur "+" (Formulaire vide)
3. Titre : "Questionnaire MOUTOUCHI - Outil enseignants"

### Étape 2 : Copier-coller les questions (15 min)

**Source** : `business/questionnaire-validation-marche.md`

**Questions essentielles (version courte)** :

```
PARTIE 1 : Profil

Q1. Dans quelle académie enseignez-vous ?
Type : Liste déroulante
Options : Guyane, Martinique, Guadeloupe, Réunion, Mayotte, Métropole

Q2. Quel niveau enseignez-vous ?
Type : Cases à cocher
Options : CP, CE1, CE2, CM1, CM2

PARTIE 2 : Le problème

Q3. Combien de temps passez-vous PAR SEMAINE à préparer vos cahiers journaux, fiches et diaporamas ?
Type : Choix multiples
Options : < 1h, 1-2h, 3-4h, 5-6h, Plus de 6h

Q4. Quel est votre PRINCIPAL problème avec la préparation ?
Type : Choix multiples
Options :
- Trop chronophage
- Difficile de différencier
- Manque de ressources contextualisées (région)
- Répétitif et ennuyeux

PARTIE 3 : La solution

Q5. Si un outil générait AUTOMATIQUEMENT vos cahiers journaux en 3 minutes (avec différenciation et contexte local), sur 10 ce serait utile à combien ?
Type : Échelle linéaire (1 à 10)

Q6. Seriez-vous prêt(e) à PAYER pour cet outil ?
Type : Choix multiples
Options : Oui certainement, Oui probablement, Peut-être, Non

Q7. Quel prix MENSUEL vous semblerait acceptable ?
Type : Choix multiples
Options : Gratuit seulement, 5-10€, 10-15€, 15-20€, 20-30€, Plus de 30€

PARTIE 4 : Bêta

Q8. Seriez-vous prêt(e) à TESTER gratuitement en avant-première ?
Type : Choix multiples
Options : Oui absolument, Oui peut-être, Non

Q9. Si oui, votre email :
Type : Texte court

Q10. Commentaires / suggestions (optionnel)
Type : Paragraphe
```

### Étape 3 : Configurer les options (3 min)

1. Paramètres > Limiter à 1 réponse : OUI
2. Recueillir les adresses e-mail : OUI
3. Réponses > Créer une feuille de calcul : OUI

### Étape 4 : Obtenir le lien (1 min)

1. Cliquer "Envoyer"
2. Icône lien 🔗
3. Raccourcir l'URL : OUI
4. **COPIER LE LIEN** : `https://forms.gle/xxxxx`

## ⏰ BLOC 4 : Faire la vidéo démo (30 min)

### Étape 1 : Installer Loom (5 min)

1. Aller sur https://loom.com
2. Télécharger l'app (gratuit)
3. Créer compte

### Étape 2 : Préparer le script (5 min)

**Source** : `business/templates-communication.md` > Script vidéo

**Plan** (3 min max) :
1. Intro (30s) : Qui je suis, le problème
2. Démo (2 min) : Montrer Make.com qui génère
3. Résultat (30s) : Ouvrir le document généré

### Étape 3 : Enregistrer (15 min)

1. Ouvrir Loom
2. Sélectionner "Screen + Cam" (écran + toi)
3. Ouvrir Make.com
4. Cliquer "Record"
5. Suivre le script
6. Terminer l'enregistrement

### Étape 4 : Partager (5 min)

1. Copier le lien Loom
2. Ajouter à la landing page (section vidéo)
3. Partager sur WhatsApp/Facebook
