# Plan d'action 30 jours - Lancement MVP MOUTOUCHI

**Objectif** : Passer de 0 à 20 utilisateurs payants en 30 jours

---

## 📊 Indicateurs de succès (KPIs)

- ✅ **50+ réponses** au questionnaire (semaine 1)
- ✅ **20+ bêta-testeurs** inscrits (semaine 2)
- ✅ **10+ utilisateurs actifs** (semaine 3)

## SEMAINE 1 : Validation marché (7 jours)

### Jour 1-2 : Créer les outils de communication

**À faire** :
1. ✅ **Questionnaire Google Forms**
   - Copier le template `questionnaire-validation-marche.md`
   - Créer le formulaire : https://forms.google.com
   - Obtenir le lien de partage

2. ✅ **Landing page simple** (gratuit, 2h max)
   - **Option A** : Carrd.co (gratuit, no-code)
   - **Option B** : Google Sites (gratuit)
   - **Option C** : Notion public (gratuit)

   **Contenu minimal** :
   - Titre : "MOUTOUCHI - Générez vos cahiers journaux en 3 minutes"
   - Sous-titre : "L'IA qui libère 3h/semaine aux enseignants"
   - 3 bénéfices clés
   - Vidéo démo (30 sec)
   - Bouton "Rejoindre la bêta"
   - Lien vers questionnaire

3. ✅ **Vidéo démo** (screencast 2-3 min)
   - Outil : Loom (gratuit)
   - Montrer : Make.com qui génère un cahier journal
   - Insister sur : contexte Guyane, différenciation, rapidité

### Jour 3-5 : Diffusion massive

**Canaux** :

1. **Réseau direct** (jour 3)

2. **Réseaux sociaux enseignants** (jour 4)
   - Groupes Facebook :
     - "Enseignants de Guyane"
     - "Professeurs des écoles - Entraide"
     - "La salle des maîtres"
   - Instagram : #profdesecoles #enseignant #guyane
   - Twitter/X : #TeamPE #EcoleALaMaison

3. **Forums spécialisés** (jour 5)
   - EDP (Enseignants Du Primaire)

   - Néoprofs

**Message type forum** :

### Jour 6-7 : Analyse et ajustements

**Actions** :
1. ✅ Analyser les réponses (au moins 30)
2. ✅ Identifier les patterns (prix acceptable, fonctions prioritaires)
3. ✅ Ajuster le produit si besoin
4. ✅ Contacter les bêta-testeurs volontaires

**Décision GO/NO-GO** :
- Si ≥ 60% "Oui prêt à payer" → GO semaine 2

## SEMAINE 2 : Préparation bêta (7 jours)

### Jour 8-10 : Finaliser le produit MVP

**Checklist technique** :

1. ✅ **Google Sheets template**
   - Créer fichier type avec données exemple
   - Préparer guide d'installation (copier-coller)

2. ✅ **Scénarios Make.com**
   - Tester à fond sur 5 semaines différentes
   - Corriger bugs
   - Optimiser temps d'exécution (< 5 min)

3. ✅ **Documentation bêta**
   - Guide installation ultra-simple (10 étapes max)
   - Vidéo tutoriel (5 min)
   - FAQ (10 questions courantes)

4. ✅ **Interface simple** (optionnel mais recommandé)
   - **Option A** : Google Apps Script → Bouton "Générer" dans Sheets
   - **Option B** : Zapier/Make webhook → Formulaire web simple
   - **Objectif** : Éviter que l'utilisateur touche à Make.com

**Process** :

1. ✅ Email aux 20 premiers bêta-testeurs :

```
- Suggérer des améliorations
```

2. ✅ **Créer un groupe WhatsApp** "MOUTOUCHI Bêta"

   - Feedback collectif

3. ✅ **Organiser une visio de lancement** (optionnel)
   - Date : Samedi/Dimanche (enseignants disponibles)

     - Démo live (20 min)

### Jour 13-14 : Monitoring et support

**Actions quotidiennes** :
- ✅ Répondre aux questions (< 2h de délai)

**Actions correctives** :

1. **Pivot produit** :
   - Interroger les non-convertis (pourquoi ?)
   - Ajuster l'offre (prix, features)

   - Tester autre région (Métropole ?)
   - Tester autre niveau (Collège ?)
